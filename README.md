# Beaming Girl Blog

Personal blog hosted on GitHub Pages with Jekyll.

## Creating New Posts

1. Create a new file in `_posts/` folder
2. Name it: `YYYY-MM-DD-your-title.md`
3. Add front matter and content:

`markdown
---
layout: post
title: "Your Post Title"
date: YYYY-MM-DD
---

Your content here in Markdown...
`

4. Commit and push - site updates automatically!
